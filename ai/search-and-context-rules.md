# Mercury Search and Context Rules

- Start with `README.md`, `docs/architecture.md`, and `docs/methodology.md`.
- Search narrowly from the named file, symbol, route, table, or model output.
- Read the owning implementation and its nearest test before exploring broadly.
- Exclude `.git`, virtual environments, dependency folders, build output, raw datasets, and model artifacts from ordinary searches.
- Use source files and tests as the authority over stale plans.
- When a library behavior matters, consult current official documentation after understanding the local code path.
- Keep investigation proportional to the requested change.
