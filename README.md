# Mercury

Customer intelligence and retention analytics for e-commerce businesses.

Mercury turns transaction data into customer segments, churn predictions, revenue-at-risk estimates, and retention recommendations. The platform combines Python, SQL, PostgreSQL, machine learning, Power BI, FastAPI, and React.

## What Mercury Answers

- Which customers are most valuable?
- Which customers are becoming inactive?
- Which customers are most likely to churn?
- How much revenue is at risk?
- Which retention action should be prioritized?

## Core Capabilities

- Clean and transform Online Retail II transaction data
- Segment customers using RFM analysis
- Engineer customer behavior features
- Predict churn probability with classification models
- Prioritize customers using value and churn risk
- Expose customer insights through an API and web interface
- Present business metrics in Power BI
